# Recordatorios App - Actividad 3

## Configuración de la API
Este proyecto consume la API pública de prueba: `https://jsonplaceholder.typicode.com/`.
No requiere claves de API ni tokens de autenticación.

Si deseas utilizar un servicio propio en el futuro, la URL base se puede modificar en el archivo:
`app/src/main/java/com/example/recordatoriosappavilaroque/data/RetrofitClient.kt`

*(En caso de requerir credenciales, se recomienda el uso de variables de entorno o un archivo local.properties que no se sube al repositorio)*.
